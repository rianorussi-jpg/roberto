CONFIGURACIÓN

1. SUPABASE
   - Abre tu proyecto.
   - Ve a SQL Editor.
   - Ejecuta el archivo: supabase/crear_tabla.sql

2. VARIABLES EN VERCEL
   Project > Settings > Environment Variables

   SUPABASE_URL
   Valor: la Project URL de Supabase
   Ejemplo: https://xxxxxxxx.supabase.co

   SUPABASE_SECRET_KEY
   Valor: la Secret key de Supabase (empieza normalmente con sb_secret_...)
   Supabase > Settings > API Keys > Secret keys
   NO pongas esta key dentro de ningún HTML.

   CONFIRMADOS_PASSWORD
   Valor: una contraseña elegida por los novios para entrar a /confirmados

   Marca las variables al menos para Production.
   Si pruebas con deployments Preview, márcalas también para Preview.

3. REDEPLOY
   Después de agregar/cambiar variables en Vercel, haz un nuevo deployment.

IMPORTANTE - CORRECCIÓN DE DUPLICADOS
-------------------------------------
Si ya tienes confirmaciones guardadas, abre Supabase > SQL Editor y ejecuta:

supabase/corregir_duplicados.sql

Ese SQL:
- elimina filas duplicadas conservando la respuesta más reciente;
- crea una restricción real para que un mismo nombre no vuelva a duplicarse.

Después sube este proyecto a Vercel y haz un nuevo deployment.


CORRECCIÓN DEL FALSO ERROR AL CONFIRMAR
---------------------------------------
Esta versión verifica la base de datos antes de mostrar un error.
Si Supabase guardó la respuesta pero Vercel/navegador no recibió la respuesta HTTP,
la invitación mostrará correctamente la confirmación en lugar de pedir un segundo clic.


IMPORTANTE PARA ESTE FIX
La API ahora depende de la restricción UNIQUE de Supabase para evitar duplicados.
Asegúrate de haber ejecutado:
supabase/corregir_duplicados.sql
